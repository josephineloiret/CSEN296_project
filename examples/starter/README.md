# Archived starter examples

These original demonstration modules are retained for reference. They are not
imported by the active application. The working equivalents are
[`app/workflow.py`](../../app/workflow.py) and
[`app/knowledge.py`](../../app/knowledge.py).

Use the [root quick start](../../README.md) or
[local development guide](../../docs/local-development.md) to run RefundGuard.

## Original starter notes

This is a starter repository for the Capstone Project.
Organize your code as per this starter repo structure.

The original starter referred to root run instructions and demo endpoints;
those have been replaced by the current application and guides.

Add and run your own Red Team tests and gather evidence.
- Review and extend default tests in demo.py
- Review and extend Red-Team tests in main.py
